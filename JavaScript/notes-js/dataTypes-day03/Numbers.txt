⚠️ الأفضل تستخدم Number.isNaN()

بدل الـ global:

isNaN(value)

لأن isNaN() القديمة بتعمل Type Conversion قبل ما تحكم.

مثال:

isNaN("123"); // false

لأنها بتحول "123" إلى 123.

لكن:

Number.isNaN("123"); // false

وهنا مفيش تحويل؛ "123" أصلًا مش NaN.

الأحسن في الكود الحديث لما تكون عايز تتحقق من NaN نفسها:

Number.isNaN(value)

شوف المثال ده 👇
isNaN("hello");         // true
Number.isNaN("hello");  // false

2️⃣ Number.isFinite()

دي بتسألك:

هل القيمة Number حقيقية ومحدودة وليست Infinity أو -Infinity أو NaN؟

Number.isFinite(100);      // true
Number.isFinite(3.14);     // true
Number.isFinite(Infinity); // false
Number.isFinite(NaN);      // false

******************************
والـ radix في parseInt()

الأفضل لما تستخدم parseInt إنك تحدد الـ base صراحة:

parseInt("1010", 2); // 10

وفي الحالة العادية:

parseInt("123", 10); // 123

Best practice:

parseInt(value, 10);

بدل الاعتماد على إن JavaScript تستنتج الـ base.

parseInt("25.75");    // 25 ✅
parseFloat("25.75");  // 25.75 ✅
Number("25.75");      // 25.75 ✅
parseInt("25px");     // 25 ✅
Number("25px");       // NaN ✅

⚠️ Imprecise Calculations — مشكلة الدقة في الأرقام
دي من أهم أجزاء Numbers للشغل، خصوصًا لو هتتعامل مع:

أسعار 💰
Cart / Checkout
Discounts
Percentages
Statistics
أي calculations فيها decimals

JavaScript بيستخدم Number بصيغة IEEE-754 64-bit floating point
وبعض الكسور العشرية لا يمكن تمثيلها بدقة كاملة في Binary

*************************
console.log(0.1 + 0.2); ......................> 0.30000000000000004

💼 ليه الموضوع مهم ليك كـ Front-End؟

تخيل Shopping Cart:
const price1 = 0.1;
const price2 = 0.2;

const total = price1 + price2;
console.log(total);
هتلاقي:
0.30000000000000004
أكيد مش عايزين نعرض للمستخدم
$0.30000000000000004

الحل الشائع للـ Display

نستخدم toFixed():
const total = Number((0.1 + 0.2).toFixed(2));
او
const total = +(0.1 + 0.2).toFixed(2);

💼 استخدام مهم جدًا مع Array

خد بالك من الحتة دي، دي مفيدة في الشغل:

const numbers = [10, 20, 5, 30];

Math.max(...numbers); // 30
Math.min(...numbers); // 5

يعني:
Math.max(...numbers);
كأنك كتبت:
Math.max(10, 20, 5, 30);
🔥 دي طريقة شائعة جدًا.
