🟢 وبعد كده React

يعني بدل ما ندخل React بعد Day 30/32 بشكل مستعجل، هنبدأ React بعد Day 42 تقريبًا.

وده في رأيي أفضل بكتير ليك.

لأن لما تشوف:

{users.map(user => ...)}

مش هتقول:

هو map دي بتعمل إيه؟

أنت أصلًا هتكون فاهمها.

ولما تشوف:

const [users, setUsers] = useState([]);

هتكون فاهم:

arrays
objects
destructuring
functions
closures
async
APIs

ولما تشوف:

useEffect(() => {
    fetchUsers();
}, []);

هتكون فاهم أصلًا:

Promises
async/await
fetch
event loop بشكل عملي
API handling

ولما تشوف:

onClick={handleClick}

هتكون فاهم Events وFunctions وCallbacks.

وده بالضبط الهدف من إننا نطوّل JavaScript شوية.
