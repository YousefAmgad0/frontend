------------------------------------2. JSON.stringify() — Options-----------------------------
JSON.stringify(value, replacer, spaces) 
ممكن تستقبل اكتر من argument

🟡 replacer		مش مهم اوي ف الشغل 
ممكن يكون:
Array
Function
أو null

1. Replacer as Array
مثلاً:
const user = {
  name: "Yousef",
  age: 23,
  role: "Frontend Developer"
};
لو عملنا:
const json = JSON.stringify(user, ["name", "age"]);
النتيجة:		{"name":"Yousef","age":23}
يعني إحنا قلنا لـ JSON.stringify():
خد بس name و age.

2. Replacer as Function

وده أقوى شوية.
const user = {
  name: "Yousef",
  age: 23,
  password: "123456"
};
ممكن نقول:

const json = JSON.stringify(user, (key, value) => {
  if (key === "password") {
    return undefined;
  }

  return value;
});

النتيجة:		{"name":"Yousef","age":23}
ليه؟

لأن:

return undefined;

معناها:

متدخلش الـ property دي في JSON.

وده يوضحلك إن replacer
بيديك تحكم في البيانات اللي هتتعمل لها serialization.

🟡 أهميته في الشغل
الفكرة مهمة، لكن استخدام replacer نفسه مش من الحاجات اللي لازم تحفظها.
ممكن تحتاجه في حالات معينة، لكن مش كل يوم.

------------------------------------------3. stringify vs parse 🔥🔥🔥-------------------------------
دي من أهم الحاجات اللي لازم تثبت.

Method			From			To
JSON.stringify()	JavaScript value	JSON String
JSON.parse()		JSON String		JavaScript value

لكن خلي بالك:
parse مش لازم ترجع Object فقط
ممكن ترجع Array أو primitive حسب الـ JSON
المصدر يوضح إن JSON يدعم objects وarrays وstrings وnumbers وbooleans وnull

مع ال Array
JSON.parse("[1, 2, 3]");
ترجع:
[1, 2, 3]

------------------------------------8. JSON + localStorage 🔥------------------------------------------
دي من أشهر الاستخدامات العملية لـ JSON.stringify() + JSON.parse().

  age: 23
};

const data = localStorage.getItem("user");
const user = JSON.parse(data);
