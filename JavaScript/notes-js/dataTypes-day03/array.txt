----------Array Methods------------
push() اضافه من الاخر , pop()  حذف من الاخر, unshift() اضافه من البدايه, shift() حذف من البدايه
const fruits = ["Apple", "Orange"];
fruits.push("Mango");
const removed = fruits.pop();
fruits.unshift("Apple");

// removed = "Mango"
// fruits = ["Apple", "Orange"]

Array.isArray(fruits); // true   عشان تعرف النوع


مهمه اوي وركز في ال return

| Method      | بتعمل إيه؟      | Return             |
| ----------- | --------------- | ------------------ |
| `push()`    | تضيف في النهاية | **length الجديد**  |
| `unshift()` | تضيف في البداية | **length الجديد**  |
| `pop()`     | تحذف من النهاية | **العنصر المحذوف** |
| `shift()`   | تحذف من البداية | **العنصر المحذوف** |

----------------------6. Loop على Array---------------------

الطريقة التقليدية
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
الطريقة الحديثة والأوضح لما تحتاج العناصر فقط
for (const item of arr) {
  console.log(item);
}

مثال:
const products = ["Phone", "Laptop", "Mouse"];
for (const product of products) {
  console.log(product);
}
الناتج:
Phone
Laptop
Mouse
