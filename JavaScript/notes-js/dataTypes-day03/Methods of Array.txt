2️⃣ splice()
تعتبر من أهم Array methods؛ لأنها تقدر تعمل:
Delete
Insert
Replace
والأهم:
بتعدل الـ original Array.

Syntax:

arr.splice(start, deleteCount, item1, item2, ...);

خلينا نفكها:

start
↓
منين أبدأ؟

deleteCount
↓
أحذف كام عنصر؟

item1, item2...
↓
أضيف إيه مكانهم؟


بتشتغل مكان ال Delete  (1)
let arr = ["I", "study", "JavaScript"];
arr.splice(1, 1);
نبدأ من:
index 1
و نحذف:
1 element
فتصبح:
["I", "JavaScript"]


B) Delete multiple elements
let arr = ["I", "study", "JavaScript", "right", "now"];
arr.splice(0, 3);
معناها:
ابدأ من index 0
احذف 3 عناصر
فيتبقى:
["right", "now"]


C) Replace
وده من أقوى استخدامات splice():
let arr = ["I", "study", "JavaScript", "right", "now"];
arr.splice(0, 3, "Let's", "dance");
اقرأها:
0 → ابدأ من index 0
3 → احذف 3 عناصر
"Let's", "dance" → حطهم مكانهم

فتصبح:
["Let's", "dance", "right", "now"]


D) splice() بترجع العناصر المحذوفة
دي مهمة جدًا.
let arr = ["I", "study", "JavaScript", "right", "now"];
let removed = arr.splice(0, 2);
arr أصبحت:
["JavaScript", "right", "now"]
لكن:
removed
تساوي:
["I", "study"]

E) Insert فقط بدون Delete
دي نقطة مهمة جدًا:
let arr = ["I", "study", "JavaScript"];
arr.splice(2, 0, "complex", "language");
هنا:
2 → ابدأ من index 2
0 → متحذفش حاجة
complex, language → أضفهم
الناتج:
["I", "study", "complex", "language", "JavaScript"]

3️⃣ slice()
بتاخد جزء من الـ Array وترجعه في Array جديدة، من غير ما تعدّل الـ Array الأصلية.
تخيل عندك:
const arr = ["A", "B", "C", "D", "E"];
وعايز تاخد "B" و"C" بس.
تقدر تعمل:
const result = arr.slice(1, 3);
console.log(result); // ["B", "C"]
console.log(arr);    // ["A", "B", "C", "D", "E"]
لاحظ إن الـ arr الأصلية زي ما هي.
1. الـ Syntax
arr.slice(start, end);
start: الـ index اللي هتبدأ منه.
end: الـ index اللي هتقف قبله، مش بتشمله.

2. لو كتبت slice(start) بس
لو ما كتبتش end 
هتجيب من البداية لحد آخر الـ Array.
const arr = ["A", "B", "C", "D", "E"];
console.log(arr.slice(2));
الناتج:
["C", "D", "E"]


-----------مهم ----------------
3. لو ما كتبتش أي arguments
const arr = ["A", "B", "C"];
const copy = arr.slice();
console.log(copy); // ["A", "B", "C"]
دي طريقة لعمل Shallow Copy للـ Array.
وده مفيد لو عايز Array جديدة بدل ما تعمل reference لنفس الـ Array.

4️⃣ concat()
بنستخدمها عشان ندمج Array مع Array تانية
أو نضيف عناصر ونرجع Array جديدة من غير ما نعدّل الأصلية.

دمج Array مع Array (1)
const arr1 = [1, 2];
const arr2 = [3, 4];
const result = arr1.concat(arr2);
console.log(result);
الناتج:
[1, 2, 3, 4]

إضافة قيم عادية  (2)
const arr = [1, 2];
const result = arr.concat(3, 4);
console.log(result); // [1, 2, 3, 4]

تقدر تدمج أكتر من Array وقيم عادية:
const arr1 = [1, 2];
const arr2 = [3, 4];
const result = arr1.concat(arr2, 5, 6);
console.log(result); // [1, 2, 3, 4, 5, 6]

3. خلي بالك من الـ Nested Arrays ⚠️
const arr = [1, 2];
const result = arr.concat([3, 4], 5);
console.log(result);
الناتج:
[1, 2, 3, 4, 5]
الـ Array اللي بتبعتها كـ argument بتتفرد لمستوى واحد.
لكن لو عندك Array متداخلة أصلًا:
const arr = [[1, 2], [3, 4]];
const result = arr.concat([5, 6]);
console.log(result);
الناتج:
[[1, 2], [3, 4], 5, 6]
لاحظ إن العناصر المتداخلة الموجودة في arr فضلت متداخلة.

4. نقطة مهمة: concat() مش Deep Copy
const user = { name: "Yousef" };
const arr1 = [user];
const arr2 = arr1.concat();
console.log(arr1 === arr2);       // false
console.log(arr1[0] === arr2[0]); // true

1. indexOf()

onst fruits = ["Apple", "Orange", "Mango"];

بدل ما يدور من الشمال لليمين، بيدور من اليمين للشمال
const fruits = ["Apple", "Orange", "Apple"];

console.log(fruits.lastIndexOf("Apple")); // 2
يعني:
indexOf()      → أول occurrence
lastIndexOf()  → آخر occurrence

-----------------------------------------1. What is filter()؟--------------------------------
بتستخدمها لما يكون عندك Array
عايز تطلع Array جديدة
فيها العناصر اللي بتحقق شرط معين
ببساطه ......... 
"هاتلي كل العناصر اللي تحقق الشرط ده."

const numbers = [10, 25, 8, 30, 15];
const result = numbers.filter((num) => num > 20);
console.log(result);
الناتج:	[25, 30]

لاحظ الفرق مع find():
find()   → أول عنصر يحقق الشرط
filter() → كل العناصر اللي تحقق الشرط
وده فرق مهم جدًا.
وكمان لو مش بيحقق الشرط في اختلاف بينهم
const numbers = [5, 10, 15];
numbers.find((num) => num > 20); // undefined
numbers.filter((num) => num > 20); // []

Callback

كـ argument
ل
لـ Function تانية
والـ Function التانية بتستدعيها.

ده الي بيحصل جوا ال filter()
ال callback 
بتاعها لازم يبقي true

الـ callback تفحص كل واحد:
Ali     → 17 >= 18 → false ❌
Yousef  → 22 >= 18 → true  ✅
Omar    → 15 >= 18 → false ❌
Ahmed   → 25 >= 18 → true  ✅
فتطلع:
[
  { name: "Yousef", age: 22 },

]

-----------------------------1. What is map()؟------------------------------
بتستخدمها لما يكون عندك Array
وعايز تعمل تحويل لكل عنصر يعني مثلا تضربه و تقسمه وهكذا
وتطلع Array جديدة بالنتائج.
const numbers = [1, 2, 3, 4];
const result = numbers.map((num) => num * 2);
console.log(result);
الناتج	[2, 4, 6, 8]
اللي حصل:
1 → 1 × 2 → 2
2 → 2 × 2 → 4
3 → 3 × 2 → 6
4 → 4 × 2 → 8

map() vs filter()

filter → بترجع Array ,  بتحقق الشروط الي انت محددها وممكن العدد يبقي اقل من الاصليه
map    → أحوّل Array , بتنفذ الي العمليات الي هتعملها والعدد بيفضل هو هو

---------------------2. map() مع Objects----------------------------------

  { name: "Omar", age: 25 }
];
عايز أطلع الأسماء فقط:
const names = users.map((user) => user.name);
console.log(names);
الناتج:		["Ali", "Yousef", "Omar"]

map() vs filter() vs reduce() 🔥
map()
→ كل عنصر يتحول
→ Array جديدة

filter()
→ نختار عناصر معينة
→ Array جديدة

reduce()
→ نختصر كل العناصر
→ قيمة واحدة غالبًا
----------------------------reduceRight()--------------------------
const numbers = [1, 2, 3, 4];
const result = numbers.reduceRight(
  (acc, current) => acc - current,
  0
);
0 - 4 = -4
-4 - 3 = -7
-7 - 2 = -9
-9 - 1 = -10
