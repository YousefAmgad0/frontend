****************************************2. DOM Tree 🌳************************************************
لأن عناصر الـ HTML بيكون بينها علاقات:

Parent
Child
Sibling

مثلاً عندنا:

<html>
  <body>
    <h1>Hello</h1>
    <p>Welcome</p>
  </body>
</html>

الـ Browser يحول ده لهيكل شجري:

Document
   │
   └── html
        │
        └── body
             ├── h1
             │    └── "Hello"
             │
             └── p
                  └── "Welcome"


--------------------------------------------1. يعني إيه Node؟--------------------------------------------

كل جزء في الـ DOM Tree اسمه Node.

يعني:

Document  → Node
html      → Node
body      → Node
h1        → Node
p         → Node
"Hello"   → Node

لكن مش كل الـ Nodes من نفس النوع.
وده مهم جدًا.

--------------------------------------------2. أهم أنواع الـ Nodes --------------------------------------------

في البداية ركز على 3:

1)Document Node
ده يمثل المستند نفسه:
Document
وده اللي عندك في JavaScript كـ:
document

2)Element Node
أي HTML element:
<body>
<h1>
<p>
<div>
<button>
كل واحد منهم Element Node.

3)Text Node
النص اللي جوه الـ element يعتبر Node برضه.

<h1>Hello</h1>
"Hello" هنا Text Node.

--------------------------------------5. نقطة مهمة جدًا: HTML مش هو DOM--------------------------------------

دي من أهم الحاجات اللي عايزك تفرق بينهم.

HTML

هو الكود اللي كتبته:

<body>
  <h1>Hello</h1>
</body>

DOM
هو التمثيل اللي الـ Browser بناه من الـ HTML:

Document
   ↓
html
   ↓
body
   ↓
h1
   ↓
"Hello"

يعني:

HTML
 ↓ Browser
DOM Tree

| Concept  | معناه                             |
| -------- | --------------------------------- |
| DOM      | تمثيل الصفحة كـ Tree/Object Model |
| Node     | أي جزء موجود في الـ DOM Tree      |
| Document | يمثل الـ Document نفسه            |
| Element  | HTML element زي `div`, `h1`, `p`  |
| Text     | النص الموجود داخل Element         |

HTML ≠ DOM
الـ HTML هو source/code.

الـ DOM هو representation منظم للصفحة 
يقدر JavaScript يتعامل معاه.

------------------------------------8. Siblings--------------------------------------------------------
من div نقدر نروح للعنصر اللي بعده:

النتيجة:		<p></p>

ولو عايز اللي قبله:
p.previousElementSibling

النتيجة:		<div></div>

⚠️ هنا بقى في Trick مهم جدًا

فيه فرق بين:

children 	و	childNodes

<div>
  <h1>Hello</h1>
  <p>Welcome</p>
</div>
div.children >>>>>>		h1 , p

div.childNodes >>>>>>>>>
ممكن تحتوي على:
Text Node  ← whitespace
h1
Text Node  ← whitespace
p
Text Node  ← whitespace

⚠️ Trick تاني: firstChild vs firstElementChild

element.firstChild
ممكن يرجع Text Node.

لكن:

element.firstElementChild
يرجع أول Element.

<div>
  <h1>Hello</h1>
</div>
