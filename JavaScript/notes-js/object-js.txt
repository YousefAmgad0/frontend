Garbage Collection (GC)
هي آلية تلقائية في JavaScript مسؤولة عن إدارة الـ Memory وتنضيف الـ Objects اللي مبقاش ليها استخدام.

let user = {
  name: "Yousef"
};
الـ variable user عنده Reference للـ Object.
إذن الـ Object:
Reachable ✅
لأن لسه نقدر نوصل له عن طريق user.

لو

user → null
{ name: "Yousef" }   ❌
مبقاش فيه أي Reference يوصل للـ Object.
إذن أصبح:
Unreachable
وساعتها Garbage Collector يقدر يتخلص منه ويحرر الـ Memory

طب لو فيه أكتر من Reference؟👇
let user = {
  name: "Yousef"
};
let admin = user;
user ─────┐
          ↓
       Object
          ↑
admin ────┘

لو عملنا:
user = null;
هيبقى:
user → null
admin ───→ Object
هل الـ Object هيتمسح؟
❌ لأ.
ليه؟
لأن admin لسه بيوصل له.
إذن الـ Object مازال:
Reachable ✅
ولو عملنا:
admin = null;
مبقاش فيه طريق نوصل بيه للـ Object.
إذن:
Unreachable → Garbage Collector can remove it.

Mark-and-Sweep 👇
دلوقتي ندخل في إزاي Garbage Collector بيعمل الشغلانة دي؟
Step 1 — Mark Roots
الـ Garbage Collector يبدأ من الـ Roots.
Step 2 — Follow References
يمشي من الـ Roots ويتبع كل الـ References.
Root
 ↓
Object A
 ↓
Object B
 ↓
Object C

كل Object يقدر يوصل له:
Mark ✅
Step 3 — يكرر العملية
يتابع الـ References الموجودة داخل الـ Objects لحد ما يخلص كل الـ reachable objects.
Step 4 — Sweep
أي Object مش معمول له Mark:
Unmarked → Remove 🗑️
ده سبب اسم:
Mark-and-Sweep
Mark → علّم الحاجات اللي لسه Reachable
Sweep → شيل اللي متعلمش عليه
